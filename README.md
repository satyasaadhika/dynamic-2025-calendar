A professional, modern, and fully responsive **calendar for the year 2025**, built with **HTML, CSS, and JavaScript**.  
Includes **real-time date & time**, **festival & holiday highlights**, **disaster awareness list**, and a sleek **light/dark theme toggle**.  
Perfect for personal use, web apps, or educational projects!

---

## 🌟 Features

-  **12-Month Layout** – Clean & scrollable grid design
-  **Live Date & Time Display** – Auto-updating top bar
-  **Light/Dark Mode** – Theme switcher with icons
-  **Indian Holidays & Festivals** – Listed month-wise
-  **Fully Responsive** – Mobile, tablet, and desktop ready
-  **Easy to Customize** – Use as template for event planners
